# Netflix Data Analysis Dashboard

This project is a Netflix Data Analysis Dashboard created using Python, Pandas, Matplotlib and Streamlit.

## Project Overview

The dashboard analyzes Netflix customer data and provides insights into:

- Monthly Revenue
- Region-wise Rating
- Device-wise Revenue
- Total Rating
- Region-wise Revenue
- Subscription Plan-wise Watch Count

## Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit

## Features

- Interactive Region filter
- Subscription Plan filter
- Customer, Revenue and Watch Count metrics
- Data visualization using charts
- Netflix-themed dashboard
- CSV file upload option

## Project Files

- `netflix.py` - Streamlit dashboard application
- `netflix.csv` - Netflix dataset
- `requirements.txt` - Required Python libraries
- `image/` - Netflix logo and banner images
